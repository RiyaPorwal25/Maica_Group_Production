4) PROJECT ARCHITECTURE
-----------------------
This is a Django MVC-style architecture:

- production\manage.py
  - Entry point for Django commands: runserver, migrate, createsuperuser, etc.

- production\production\settings.py
  - Global configuration: database, installed apps, middleware, templates, static files.

- production\production\urls.py
  - Root URL router.
  - Admin site at /admin/
  - Includes myapp URLs at root path.

- production\production\wsgi.py and asgi.py
  - WSGI/ASGI application wrappers used for deployment.

- production\myapp\
  - models.py      : defines database schema and business objects.
  - views.py       : handles page requests, form processing, business logic, export, import.
  - urls.py        : maps app-level URL patterns to view functions.
  - forms.py       : defines Django ModelForms for CustomUser, Product, Machine.
  - decorators.py  : custom access control decorators for role/module permissions.
  - admin.py       : registers models into Django admin.
  - migrations/    : database schema history and change structure.
  - templatetags/  : custom template filters/helpers.
  - management/commands/init_permissions.py : custom management command for permission initialization.

- templates/ : HTML templates for user interface.
- static/    : CSS, JavaScript, and image assets used by templates.

8) SUGGESTED SETUP COMMANDS
---------------------------
On Windows using a virtual environment:

python -m venv venv
venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install Django==6.0.1 openpyxl pandas mysqlclient

If mysqlclient fails to install, use:
python -m pip install PyMySQL

Then run:
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
